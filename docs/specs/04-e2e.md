# 04 — End-to-end generate-and-run

## Goal

Prove that `feathers new` produces a service that actually boots and responds on
`/health`. This is the acceptance-gate test for Phase 1.

## Inputs / Outputs

- Runs the full pipeline: YAML → generated service → `uv sync` → `uvicorn` → HTTP GET.
- Marked `@pytest.mark.slow`; opt-in via `pytest -m slow`.

## Test cases

- `test_generate_users_service_boots_and_healthchecks`:
  1. Render `demos/users.yaml` to a tmp dir.
  2. Run `uv sync` inside the generated dir. Must exit 0.
  3. Launch `uv run uvicorn <pkg>.main:app --port <free>` as a subprocess.
  4. Poll `GET http://localhost:<port>/health` up to `HEALTH_DEADLINE_S` (40s — a cold
     CI runner pays for a fresh interpreter and import graph before uvicorn binds).
     Must return 200 with JSON `{"status":"ok","service":"hello_users","db":"ok",...}`.
  5. With `BASTION_SIGNING_KEY_PUBLIC` set to a throwaway key, exercise the generated CRUD
     against the SQLite fallback: no token ⇒ 401 `missing_platform_token`; a token for
     another service ⇒ 401 `invalid_platform_token`; create (admin) → viewer create ⇒ 403
     → get → list → unknown id 404 → delete 204 → get/delete 404 → not listed.
  6. Kill subprocess cleanly.

- `test_generated_service_passes_its_own_gates[users|kitchen]`:
  - Render the demo and the kitchen-sink shape (`tests/shapes.py`), `uv sync --all-extras`,
    then run the *generated* project's own `ruff check`, `ruff format --check`, `mypy`
    (strict) and `pytest -q` twice. All must exit 0, and no SQLite file may be left in the
    project — this is what proves the emitted contract-v2 conformance tests and per-model
    tests are live, not inert, and that the suite is isolated and re-runnable.

- `test_generated_service_has_platform_middleware`:
  - After render, the generated service's `src/<pkg>/core/platform.py` exists and
    defines `install_platform_middleware`.

- `test_generated_ci_workflow_valid_yaml`:
  - After render, `.github/workflows/ci.yml` exists and parses as valid YAML with
    `jobs.lint`, `jobs.test`, `jobs.build`.

## Acceptance

- Full pipeline completes in <60 seconds on a cold run (uv sync dominates).
- No network access required except what uv already does for dep resolution.
- Test runs in CI on every push (slow marker opt-in via the ci workflow).
